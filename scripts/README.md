# Scripts

Automation belongs here once the first manual experiment has established the workflow.

Planned utilities:

1. generate control and treatment outputs
2. randomize response order for blind judging
3. call the judge model
4. write raw results to CSV or JSON
5. aggregate win rates and dimension scores
6. update experiment summaries

Do not overbuild before Experiment 001 is run end to end manually or with a minimal script.
