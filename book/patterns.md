# Emerging Patterns

This file tracks patterns that appear across multiple experiments.

Do not promote a single experiment into a general rule. Add patterns here only when at least two experiments point in the same direction.

Potential dimensions to watch:

* encouragement
* challenge
* mission framing
* stakes
* caution
* identity
* ritual language
* fictional or cinematic framing
* confidence
* seriousness
* placement effects

## Current patterns

None yet. Promotion requires two experiments pointing the same way, and only one is
complete.

### Candidates on one experiment (not patterns)

* **Instruction content beats tone.** Experiment 001: the only condition that moved any
  measure was the plain "be especially thorough and check your work carefully", not the
  cinematic phrase. Needs a second experiment before it is a pattern.
* **Appended text is not automatically helpful.** Generic encouragement ("Good luck. Do
  your best.") scored at or below the empty control on the objective measure in
  Experiment 001. The active-control ladder in `METHODOLOGY.md` assumes appended text may
  help on its own; in this one run, it did not.
* **Saturating measures shrink effective n.** With a ceilinged outcome, the number that
  governs statistical power is not the task count but the count of tasks whose scores
  actually differ between conditions. Experiment 001's `C_vs_D` had 20 tasks and an
  effective n of 5.

Each of these is one data point. None is a rule.
